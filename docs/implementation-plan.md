# ConflictCompass — 实施计划

## 开发原则

- **小步快跑**：每步只做一件事，做完验证再做下一步
- **稳定优先**：不追求一次写完所有代码，每个文件写完即测
- **安全第一**：API Key 永远不硬编码，数据库操作使用参数化查询

---

## 第 1 步：项目骨架（预计 10 分钟）

**目标：** 搭建可运行的最小项目骨架，验证环境

**产出：**
- [x] 创建目录结构（static/、data/、docs/、devlog/）
