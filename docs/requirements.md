# ConflictCompass — 项目需求文档

## 1. 项目概述

**项目名称：** ConflictCompass（冲突罗盘）
**项目定位：** AI 辅助 HR 沟通话术生成与合规检查工具
**目标用户：** 企业 HR 从业人员（非技术背景）
**运行环境：** Windows 电脑，浏览器中运行，双击 bat 脚本启动

## 2. 核心痛点

高冲突 HR 沟通场景（裁员、绩效改进、违纪警告、离职挽留等）中：
- HR 不知如何组织语言、如何开口
- 容易触犯劳动法红线，给企业带来法律风险
- 用语不当容易激化矛盾，导致劳资纠纷升级
- 缺乏结构化的沟通框架和合规自查手段

## 3. 功能需求

### 3.1 话术生成工作台（主功能）

**F1.1 生命周期阶段选择**
- 入职融入 / 在岗管理 / 纪律与冲突 / 异动与调整 / 离职与善后
- 每个阶段展开对应的具体场景

**F1.2 沟通背景信息填写**
- 对方职级：一线员工 / 基层管理 / 中层管理 / 高层管理
- 对方情绪预判：平静 / 焦虑 / 防御 / 愤怒 / 悲伤
- 期望语气：正式严肃 / 温和关切 / 坚定但尊重 / 鼓励支持
- 补充信息：自由文本输入

**F1.3 话术生成**
- 点击生成后，AI 输出带【开场】【核心】【收尾】标签的结构化话术
- 同时输出「对方反应预判」卡片（3~5 个可能的问题 + 应对话术）

**F1.4 话术优化（流水线）**
- 在生成结果页点击「优化」按钮
- 选择优化方向：更温和 / 更专业 / 更坚定 / 更简洁 / 强化合规
- 可输入补充要求（如"加上补偿方案说明"）
- AI 输出优化后话术 + 修改说明

### 3.2 合规检查

**F2.1 劳动法红线检查**
- 9 大类红线：歧视、违法解除、强迫辞职、威胁恐吓、工资克扣、隐私侵犯、名誉损害、程序违规、竞业限制滥用
- 输出：✅ 通过 / ⚠️ 提醒 / 🚫 违规 三档
- 🚫 违规项附带《劳动合同法》条款原文引用

**F2.2 禁忌词扫描**
- 在话术结果中自动内嵌扫描
- 升级性词汇 → 标红 + 替换建议
- 对抗性词汇 → 橙色标记 + 替换建议
- 支持「一键替换」

### 3.3 历史记录

**F3.1 保存与浏览**
- 每次生成/优化的话术自动保存
- 按生命周期阶段分类、按日期/关键词搜索

**F3.2 一键复用**
- 从历史记录中加载话术到工作台继续编辑优化

### 3.4 场景模板管理

**F4.1 预置模板**
- 6 个生命周期 + 默认场景模板

**F4.2 自定义模板**
- 创建、编辑、删除自定义模板
- 模板可预设：场景名称、默认语气、常用补充说明

## 4. 验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC1 | 启动 | 双击 start.bat → 自动安装依赖 → 打开浏览器 → 看到首页 |
| AC2 | 话术生成 | 选择场景+填写信息 → 点击生成 → 输出含【开场】【核心】【收尾】的结构化话术 |
| AC3 | 反应预判 | 生成结果包含对方可能问题的预判卡片 |
| AC4 | 话术优化 | 点击优化 → 选择方向 → 输出优化后话术 + 修改说明 |
| AC5 | 合规检查 | 输入含违规文本 → 标红违规项 → 附带法条原文 |
| AC6 | 禁忌词扫描 | 话术中命中禁忌词标红 → 显示替换建议 |
| AC7 | 历史记录 | 话术自动保存 → 可搜索 → 可复用 |
| AC8 | 模板管理 | 可创建/编辑/删除场景模板 |
