# ConflictCompass — 设计规范

## 1. 设计理念

**关键词：** 简洁、专业、亲和、可信赖

营造一种让 HR 感到「有靠山」的沟通准备体验——不是冷冰冰的工具，而是值得信赖的顾问。

## 2. 色彩体系

| 色值 | 名称 | 用途 |
|------|------|------|
| `#E8F4FD` | 淡蓝底色 | 页面背景 |
| `#FFFFFF` | 白色 | 卡片/内容区背景 |
| `#5B9BD5` | 主蓝色 | 按钮、导航高亮、主标题 |
| `#3A7CC3` | 深蓝色 | 按钮悬停、激活态 |
| `#2C5282` | 最深蓝 | 侧边导航背景 |
| `#F7FAFC` | 浅灰 | 输入框背景、分隔区 |
| `#4A5568` | 正文灰 | 正文文字 |
| `#718096` | 辅助灰 | 辅助文字、标签 |
| `#DC3545` | 警示红 | 违规标记、禁忌词标红 |
| `#FD7E14` | 提醒橙 | 警告标记、对抗性词汇 |
| `#28A745` | 通过绿 | 合规通过标记 |

## 3. 布局规范

### 整体布局
```
┌──────────┬──────────────────────────────┐
│          │                              │
│  左侧    │        右侧内容区              │
│  导航    │                              │
│  220px   │        自适应宽度              │
│          │                              │
└──────────┴──────────────────────────────┘
```

### 内容区最大宽度
- 话术工作台：900px（居中）
- 表单卡片：600px（居中）

## 4. 组件规范

### 按钮
- 主按钮：`#5B9BD5` 背景，白色文字，圆角 6px
- 次级按钮：白色背景，`#5B9BD5` 边框和文字
- 危险按钮：`#DC3545` 背景（仅用于删除等不可逆操作）
- 高度：40px，内边距 12px 24px

### 输入框
- 边框：1px solid #E2E8F0
- 聚焦：边框变为 #5B9BD5，加外发光
- 圆角：8px，高度：40px
- 文本域：最小高度 120px

### 卡片
- 白色背景，圆角 12px
- 阴影：0 2px 8px rgba(0,0,0,0.08)
- 内边距：24px

### 选择器（下拉/标签选择）
- 场景选择用卡片式，选中态蓝色边框
- 生命周期阶段用横向 Tab 切换

## 6. 字体
- 首选：系统默认中文字体（微软雅黑 / PingFang SC）
- 代码/英文：Segoe UI
- 正文：15px，行高 1.6
- 标题：18-24px，加粗

## 7. 响应式
- 最小支持宽度：1024px
- 目标设备：桌面浏览器（不要求移动端适配）
